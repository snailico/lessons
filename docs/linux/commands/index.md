# Linux 命令分类总结

按实际工作场景划分，标注高频命令与作用；区分 **Shell 内置** 与 **外部命令**。

- **内置命令**：Shell 内部实现，速度快（如 `cd`、`pwd`、`jobs`）
- **外部命令**：磁盘上独立可执行程序（如 `ls`、`grep`、`curl`）

工作重点掌握：**文件目录操作** + `less`/`tail`/`grep` + **进程查看** + `curl`/`wget`，可覆盖绝大多数日常运维场景。

---

## 1. 文件与目录操作（最高频）

处理目录切换、创建删除、复制移动、链接、属主、权限、查找文件。

| 命令 | 说明 |
| --- | --- |
| [`pwd`](./pwd) | 打印当前工作目录（内置） |
| [`cd`](./cd) | 切换目录（内置），`cd ..` 回到上级 |
| [`ls`](./ls) | 列出目录内容；`-l` 详情、`-a` 隐藏文件、`-h` 人性化大小 |
| [`mkdir`](./mkdir) | 创建目录；`-p` 递归创建多级 |
| [`rm`](./rm) | 删除文件/目录；`-r` 递归，`-f` 强制，**无回收站，高危** |
| [`cp`](./cp) | 复制；`-r` 复制目录 |
| [`mv`](./mv) | 移动、重命名 |
| [`touch`](./touch) | 创建空文件，更新时间戳 |
| [`ln`](./ln) | 创建链接；`ln -s` 软链接 |
| [`chown`](./chown) | 修改所有者/所属组；`-R` 递归 |
| [`chmod`](./chmod) | 修改 rwx 权限；数字模式 755、644 |
| [`stat`](./stat) | 查看元数据：权限、属主、时间、inode |
| [`find`](./find) | 递归查找，可按名称、大小、时间筛选 |

## 2. 文本内容处理（日志排查、脚本处理）

查看、过滤、切割、统计、替换文本，大量配合管道 `|` 组合使用。

| 命令 | 说明 |
| --- | --- |
| [`cat`](./cat) | 一次性输出整个文件 |
| [`less`](./less) | 分页浏览，支持搜索（日志阅读首选） |
| [`head`](./head) | 查看开头；`-n 20` 前 20 行 |
| [`tail`](./tail) | 查看末尾；`-f` 实时跟踪日志 |
| [`grep`](./grep) | 文本搜索、正则；`-i` 忽略大小写，`-n` 行号，`-v` 反向 |
| [`cut`](./cut) | 按分隔符切割，提取指定列 |
| [`sort`](./sort) | 文本行排序 |
| [`uniq`](./uniq) | 去重，一般搭配 sort |
| [`wc`](./wc) | 统计行/词/字符；`-l` 行数 |
| [`sed`](./sed) | 流编辑，行级替换/删除 |
| [`awk`](./awk) | 按列解析，支持简单脚本逻辑 |
| [`tr`](./tr) | 字符替换、删除 |
| [`expr`](./expr) | 老式整数/字符串工具；优先 bash 内置替代 |

## 重要区分

1. **Shell 内置**：`cd`、`pwd`、`jobs`、`fg`、`bg`、`type` — shell 内部执行，无独立可执行文件。
2. **外部命令**：`ls`、`rm`、`chown`、`grep`、`expr` — 磁盘上的独立程序，会创建子进程。
